# Documentacao

## Objetivo

Centralizar a documentacao tecnica necessaria para manutencao e evolucao do projeto por uma equipe pequena.

## Arquivos

- `arquitetura.md`: visao arquitetural, stack, camadas e motivos das escolhas
- `decisoes-e-tradeoffs.md`: decisoes tecnicas registradas e trade-offs aceitos
- `guia-de-manutencao.md`: convencoes para evolucao do sistema
- `qualidade-e-testes.md`: estrategia pragmatica de qualidade e testes

## Ordem Recomendada De Leitura

1. `arquitetura.md`
2. `decisoes-e-tradeoffs.md`
3. `guia-de-manutencao.md`
4. `qualidade-e-testes.md`
